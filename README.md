## 🌟 Featured Projects

실제 배포(Release)와 완성도 높은 기술 문서가 갖춰진 대표 프로젝트입니다.

### 1. [JuTell](https://github.com/ju0o/jutell) — AI Agent Work Verification Layer
[![npm](https://img.shields.io/npm/v/jutell.svg?style=flat-square)](https://www.npmjs.com/package/jutell)
- **What it is:** AI 코딩 에이전트(Codex, Claude Code, OpenCode)가 실행한 작업을 Git 변경점과 대조해 검증하고 투명성 영수증을 발행하는 도구
- **Status:** npm 정식 배포 (`v2.2.0`) · 전수 단위 테스트 통과 · 영문/한국어 상세 문서 완비
- **Quick Start:** `npm install -g jutell`

### 2. [DIOS](https://github.com/ju0o/Dios) — AI Agent Skillboard
[![Release](https://img.shields.io/github/v/release/ju0o/Dios?style=flat-square&color=success)](https://github.com/ju0o/Dios/releases)
- **What it is:** AI 에이전트 스킬(`SKILL.md`)을 한곳에 모아 관리하고 클릭 한 번으로 프롬프트에 붙여 쓰는 Windows 데스크톱 앱
- **Status:** Release `v0.2.7` 배포 중 (`.exe` 다운로드 지원) · 로컬 번역 엔진 탑재
- **Demo:** [60초 시연 영상](https://youtu.be/IQigOMQEUk4)

### 3. [JTT (Ju0 Terminal Tower)](https://github.com/ju0o/JTT) — Local-first Agent Control Tower
[![Release](https://img.shields.io/github/v/release/ju0o/JTT?include_prereleases&style=flat-square)](https://github.com/ju0o/JTT/releases)
- **What it is:** 다중 AI 코딩 에이전트의 터미널을 실시간 모니터링하고 대화·결과를 취합하는 로컬 tmux 관제탑
- **Status:** Release Candidate (`v0.3.0 RC3`) · 영문/한국어 문서 완비

### 4. [JuRelay](https://github.com/ju0o/JuRelay) — Multi-Agent Relay Pipeline
[![Release](https://img.shields.io/github/v/release/ju0o/JuRelay?style=flat-square)](https://github.com/ju0o/JuRelay/releases)
- **What it is:** AI들이 **계획(PM) → 구현(Worker) → 검사(QA)** 파이프라인을 스스로 이어가도록 조율하는 Windows 앱 + CLI
- **Status:** Release `v0.3.1` · [실제 구동 영상](https://youtu.be/BrnZxxEWzf4)

### 5. [Jusage (tray-left)](https://github.com/ju0o/tray-left) — Windows Tray Codex Monitor
[![Release](https://img.shields.io/github/v/release/ju0o/tray-left?style=flat-square)](https://github.com/ju0o/tray-left/releases)
- **What it is:** Windows 시계 옆 트레이 영역에서 OpenAI Codex의 남은 쿼터/사용량을 실시간으로 보여주는 가벼운 네이티브 유틸리티
- **Status:** Release `v0.2.0` (`jusage.exe` 즉시 실행 지원)
