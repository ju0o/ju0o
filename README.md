# 주엉쓰 (Ju0o)

코딩을 모르는 사람이 AI를 여러 개 써도 흔들리지 않게 하는 도구를 만듭니다.
설치 파일 하나면 되는 **Windows 앱** 위주로 만들고 있습니다.

## AI 에이전트 제품군

같은 줄에서 나란히 도는 세 가지입니다.

| 저장소 | 하는 일 |
|---|---|
| [JuActl](https://github.com/ju0o/JuActl) | 여러 AI 창에 지시를 한 번에 보내고 답을 받는 리모컨 |
| [JuRelay](https://github.com/ju0o/JuRelay) | AI들이 스스로 계획(PM) → 만들기(Worker) → 검사(QA)하게 하는 셋톱박스 |
| [JuControler](https://github.com/ju0o/JuControler) | 여러 AI 프로젝트의 진행을 한 화면에 모으는 읽기 전용 상태판 |

## 그 외 공개 도구

- [jutell](https://github.com/ju0o/jutell) — AI 코딩 에이전트가 실제로 뭘 했는지 확인하는 레이어 (npm: `jutell`)
- [Dios](https://github.com/ju0o/Dios) — AI 에이전트 스킬을 한 곳에 두고 눌러서 붙이는 Windows 앱
- [JuQode](https://github.com/ju0o/JuQode) — Claude Code에 자연어로 지시하고 바뀐 내용을 카드로 확인하는 워크벤치
- [JuDoctor](https://github.com/ju0o/JuDoctor) — 지속된 근거로만 업그레이드를 권하는 PC 건강 모니터
- [JuPaper](https://github.com/ju0o/JuPaper) — 손글씨·스케치·글을 섞어 쓰는 자유 노트
- [JuAi-Bot](https://github.com/ju0o/JuAi-Bot) — AI 봇 4명이 운영하는 디스코드 커뮤니티 봇
- [Hermess-discord-orchestrator](https://github.com/ju0o/Hermess-discord-orchestrator) — 디스코드 안에서 도는 파일 기반 멀티 에이전트
